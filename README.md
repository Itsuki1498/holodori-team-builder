# ホロドリ構成シミュレーター

現行バージョン: **v0.9.8**

ホロライブドリームスのリーダー、サブカード、ホロメンボード、1曲分のスキル発動を確認する静的シミュレーターです。

## 公開方法

このリポジトリをGitHub Pagesで公開する場合は、Pagesの公開元を `main` ブランチのルートに設定してください。

画像・ゲームデータの出典は画面内の情報および攻略Wikiを確認してください。

本ツールはゲーム本体へアクセスしたり、ゲームクライアントからデータを抜き出したりしていない、独立したクリーンなファンメイドツールです。公開情報をもとに収録したデータを使って、編成・ボード・スキルの計算をブラウザ上で行います。

編成提案と育成優先度のおすすめロジックは暫定版です。編成順、スキル条件、発動率、曲設定などの組み合わせによって、実際の最適解と一致しない場合があります。

v0.9.7では、理想スキル短縮と短縮バランス重視の提案計算から現在のボード短縮を切り離しました。ボードを編集しても、短縮提案の結果がボードの現在値に引きずられません。イベント「アルティメットサマー！ for Me？」の水着ルーナ「のんびり姫のおねだりビーチ」を★5として修正しています。今回の添付画像で数値が確認できない基礎ステータスは、既存カードの同レアリティ・得意ステータス帯を基準に仮置きしています。
